# 功能与规则

本文是用户视角的功能说明；逐字段契约以 [SPEC.md](../SPEC.md) 为准，UI 规则以 [DESIGN.md](../DESIGN.md) 为准。

## 一条核心流程

```text
init → import 交割单 → snapshot 持仓 → check 对账 → report 报告
```

`explain`、`status`、`backup`、`reset` 是围绕这条流程的核对与维护命令；`demo` 用内置数据跑通同一条流程。

## 支持的输入

### 交割单 CSV

必需列：`日期`、`操作`。其余列缺失按空处理。

| 逻辑列 | 可识别别名（去空格、全角转半角、小写后比较） |
|---|---|
| 日期 | 成交日期、发生日期、交易日期、日期、交收日期、date |
| 操作 | 操作、买卖标志、业务名称、摘要、交易类型、business |
| 代码 | 证券代码、股票代码、代码、symbol、code |
| 名称 | 证券名称、股票名称、名称、name |
| 数量 | 成交数量、发生数量、数量、qty、quantity |
| 价格 | 成交价格、成交均价、价格、price |
| 金额 | 成交金额、发生金额、金额、amount |
| 佣金 | 手续费、佣金、commission |
| 印花税 | 印花税、tax |
| 过户费 | 过户费、transferfee |
| 其他费用 | 其他费用、规费、otherfee |

操作文本按顺序识别：

| 文本包含 | 类型 | 说明 |
|---|---|---|
| 税、扣税、代扣 | `fee` | 红利税等，金额为负 |
| 红股、送股、转增、送转 | `bonus_share` | 只增数量，不增成本 |
| 红利、股息、分红 | `dividend` | 现金分红 |
| 配股 | `rights_issue` | 配股缴款，增加数量与成本 |
| 中签、新股 | `ipo_allot` | 按买入入账 |
| 费用、手续费、佣金、规费 | `fee` | 费用支出 |
| 利息 | `interest` | 金额为正记利息收入，为负按费用 |
| 银证转入/转出 | `transfer_in` / `transfer_out` | 只影响现金，不影响持仓 |
| 买入 | `buy` | |
| 卖出 | `sell` | |
| 其他 | `other` | 入库但不参与账本，摘要提示“未识别” |

同一行同时出现现金分红和送股/转增词 → 该行报错，要求拆成两行，避免静默丢掉现金部分。

### 持仓快照 CSV

必需列：`代码`、`数量`；可选 `名称`、`成本价`、`市值`。快照不需要日期列；日期由 `--as-of` 决定。同一文件同代码出现多次取最后一行，并给警告。

### 手工价格 CSV（`report --prices`）

必需 `code,close`，可选 `date`。价格日期晚于报告截止日会被忽略并警告；代码不在库中会自动建标的（这是为了支持先有价格、后导入交易的场景）。

## 金额语义

- `amount` 是**不含费用的本金现金流**：买入为负、卖出为正、分红/利息为正、费用为负。
- 四个费用字段都存正数；费用行只通过 `fee_other` 计一次，避免重复。
- 交易净现金流：买入类 `amount - fee_total`，卖出 `amount - fee_total`，费用行直接用 `amount`（已经是负数）。
- 所有金额输出 2 位；数量/价格/成本 4 位；内部成本计算保留 12 位，卖出用 `total_cost × 卖出数量 ÷ 卖出前数量`，不拿 4 位均价反乘。

## 成本与盈亏

- 买入/配股/中签：`total_cost += gross + fees`。
- 卖出：`cost_out = total_cost × 卖出数量 ÷ 卖出前数量`；`realized += (gross - fees) - cost_out`。
- 送股/转增：只加数量，成本不变。
- 分红：计入分红；红利税作为费用，不冲减分红。
- 利息：正数计入利息收入，负数按费用。
- 清仓：`total_cost=0`、`avgCost=null`，已实现保留。
- 卖出超过持仓 → `ledger_negative`，整个命令失败（不静默截断）。

## 对账

默认取每个账户的最新快照：先比日期，再比同日 `id`。没有快照的账户跳过并警告；`--as-of` 要求每个被查账户都有该日快照。

7 种状态：

| 状态 | 含义 |
|---|---|
| `matched` | 数量和成本都在容差内 |
| `qty_missing` | 快照数量 > 账本数量 |
| `qty_extra` | 账本数量 > 快照数量 |
| `only_ledger` | 快照没有该代码，账本有 |
| `only_snapshot` | 快照有该代码，账本没有任何持仓交易 |
| `cost_off` | 数量一致，成本差超过容差 |
| `no_cost` | 快照没有成本价 |

成本容差：`max(1.00, 快照成本价 × 0.5%)`。差异最多给 2 条提示：90 天内的送转、90 天内的分红、最后交易在 30 天前。

`--strict` 有任一非 `matched` 时退出 3，适合放进每月脚本。

## 报告

- 文本：终端可读；默认格式。
- HTML：单文件，无 JS、无外部 CSS/字体；亮/暗自动切换；375px 下列表变卡片。示例：[亮色](../docs/screenshots/report-light.png)、[暗色](../docs/screenshots/report-dark.png)、[375px](../docs/screenshots/report-375.png)。
- JSON：稳定字段，供脚本读取；`--json` 时不写报告文件。

字段：

- 汇总：总市值、总成本、浮动盈亏/收益率、已实现盈亏、分红、利息、费用（佣金/印花税/过户费/其他）、费用/成交额、XIRR、已定价/无价数量。
- 持仓：代码、名称、数量、成本价、现价、市值、占比、浮动盈亏、收益率。
- 集中度：前 3/前 5 占比；无价标的不计入分母。
- 交易统计：总笔数、买入/卖出笔数、成交额。
- 来源：导入文件名与读取行数（同一文件多次导入取最后一次）。
- 警告：无价、手工价被忽略、行情部分失败、XIRR 用成本价替代期末市值等。

XIRR 用真实现金流：买入 `-(gross+fees)`、卖出 `gross-fees`、分红/利息为正、费用为负，期末加总市值（无价用成本）。ACT/365；无解时 `xirr=null` 并给原因。

## 行情

- `off`（默认）：只用 `prices` 表缓存，不联网。
- `mock`：内置 8 个代码的固定价格；用于演示和测试。
- `live`：腾讯公开报价 `https://qt.gtimg.cn/q=<codes>`，GB18030；只读名称/现价/昨收三个字段；每批 ≤60 个代码，批间隔 ≥1 秒，超时 8 秒，重试 2 次（1/2 秒退避），一次运行总上限 30 秒。
- 全部失败且无缓存 → 退出 4，不生成报告；部分失败 → 报告标注无价，不编造。

该接口没有官方文档，字段靠 2026-10-29 实测固定；详见 [external-apis.md](external-apis.md)。

## 限制

- 单文件 ≤100 MiB，数据行 ≤200,000；超过拒绝，不部分写入。
- 金额 ≤1e12，数量/价格 ≤1e9；文本字段 ≤200 字符（账户名/名称 ≤40）。
- 只支持 A 股股票/ETF/可转债；不支持基金穿透、期权/期货/融资融券/多币种。
- 没有自动盯盘、推送、云同步；没有交易执行。

## 示例

```bash
holdbook demo --dir holdbook-demo
holdbook --data-dir holdbook-demo/data report --market mock --format html --out holdbook-demo/report.html
holdbook --data-dir holdbook-demo/data check
holdbook --data-dir holdbook-demo/data explain 600519.SH
```
