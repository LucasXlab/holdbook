# 项目决定记录

## 2026-10-29：从「基金穿透」改为「持仓簿」

原始选题最高分是「多账户基金穿透与加仓规划器（Lookfolio）」。写规格前核对数据可得性：

- 基金穿透需要每只基金的完整成分与权重。国内公募只公开季报前十大；ETF 成分在各发行人官网，格式和条款会变，v0.1.0 无法保证覆盖用户实际持有的基金。
- 如果大部分基金显示「缺成分」，核心流程就跑不通，报告会变成数据整理负担。
- 「跨券商成本与资本利得账本」的输入是用户自己的券商交割单和持仓快照，导出即可得，不依赖第三方数据，账目可逐行核对。

因此改为「持仓簿 Holdbook」：导入交割单 → 持仓快照 → 对账 → 报告。原始选题与打分保留在 `docs/选题.md` 第五节，修订说明在文首和第九节。
