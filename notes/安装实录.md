# 安装与使用实录

记录时间：2026-10-29（America/New_York）。环境：macOS arm64、Python 3.13.5、SQLite 3.49.1、zsh；不使用 Docker/Node/数据库服务。

## 1. 全新克隆安装

```bash
rm -rf /tmp/hbfresh
git clone /Users/you/NO/holdbook /tmp/hbfresh
cd /tmp/hbfresh
python3 -m venv .venv
.venv/bin/pip install .
.venv/bin/holdbook --version
```

结果：

```text
install_seconds=2.14
holdbook 0.1.0
```

`pip install` 只有标准库依赖；没有编译、没有网络包（pip 自身缓存目录不可写，出现一条环境警告，与本项目无关）。

## 2. 按 README 跑核心流程

```bash
export HOLDBOOK_DATA_DIR=/tmp/hbfresh/data
export HOLDBOOK_NOW=2026-10-29T12:00:00Z
.venv/bin/holdbook init
.venv/bin/holdbook import demo/华泰_交割单_2025-2026.csv --account 华泰 --broker 华泰证券
.venv/bin/holdbook snapshot demo/华泰_持仓_20261029.csv --account 华泰 --as-of 2026-10-29
.venv/bin/holdbook check
.venv/bin/holdbook report --market mock --format html --out /tmp/hbfresh/report.html
```

实际输出：


随后 `check --strict` 返回 0；`explain 600519.SH` 输出 4 笔重放；`status` 显示 schema 1、账户 1、标的 4、行情 off；`backup` 生成 81,920 字节副本；`demo` 生成差异 1 只的演示报告。

| # | 场景 | 命令要点 | 结果 |

| 2 | 重复导入同一文件 | 再 `import` | 0；新增 0，跳过 9 |

## 4. 发现的异常与处理

1. **README 的 `--out` 示例缺少 `--format html`**。实际命令返回 2；已把 README 和 README_EN 改成 `--format html --out report.html`。这是文档问题，不是代码 bug。
2. **`status` 把 CASH 算成标的**。演示库显示“标的 5”，报告只有 4 只。已让 `status` 排除 `CASH.CASH`，并加 `CliTests` 断言 `instruments == 4`；`docs/deviations.md` 第 9 条同步。
3. **无价标的一次打印 50 条警告**。10,000 行/50 只标的的 report 生成 50 条 `missing_price`。已聚合成一条“50 只标的没有价格……”，保留前 5 个代码；`ReportTests.test_no_price` 改为断言 1 条。
4. **`demo` 报告没有数据来源**。演示只直接插交易，没有写 `imports`，报告显示“无导入记录”。已补 `insert_import`，并在 `CliTests` 断言 `示例_交割单.csv`。
5. **pip 缓存目录不可写**。`pip install` 打印环境警告，安装仍成功；这是本机 pip 权限，不是项目依赖问题。
